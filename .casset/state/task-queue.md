# Casset — صف کار خودکار (Autonomous Task Queue)

> این فایل توسط Scheduled Task «casset-autonomous-cycle» خوانده می‌شود.

> و وضعیتش را به `🔄 in-review` تغییر می‌دهد. هرگز به `main` push/merge نمی‌کند.
