# Casset Project Brain

This directory is the canonical engineering brain of Casset.

## Read order for humans and agents
1. `constitution.md`
2. `architecture/current-state.md`
3. `architecture/domains.md`
4. `architecture/release-flow.md`
5. `roadmap.md`
6. `state/current.md`
7. `state/technical-debt.md`
8. `agents/README.md`

## Purpose
The Brain captures stable product intent, architecture boundaries, current project state, technical debt, release criteria and agent guardrails.

## Synchronization rule
Repository Brain is the canonical engineering copy. Notion mirrors the project-management and documentation view. Changes to architecture must be reflected in both systems.
