# راهنمای تست پروژه Casset

> این فایل چک‌لیست کامل تست پروژه است — هم تست خودکار، هم تست دستی مرورگر.

---

## بخش ۱ — تست خودکار (Automated)

### ۱.۱ تست کل پروژه

```powershell
cd D:\Casset.ir\casset-django
python manage.py test
```

**انتظار:** همه تست‌ها `ok` باشند، خط آخر `OK`.

اگر خطا داد، نوع خطا مهم است:

| نوع | معنی | اولویت |
|---|---|---|
| `ERROR` | کد crash کرده (باگ واقعی) | 🔴 فوری |
| `FAIL` | assert غلط بود (منطق اشتباه) | 🟠 مهم |

---

### ۱.۲ تست هر اپ جداگانه

وقتی می‌خواهی سریع فقط یک بخش را چک کنی:

```powershell
python manage.py test accounts
python manage.py test tracks
python manage.py test plays
python manage.py test billing
python manage.py test notifications
python manage.py test core.tests_smoke
```

---

### ۱.۳ Smoke test — همه صفحات

این مهم‌ترین تست است. چک می‌کند **هر صفحه سایت بدون crash لود می‌شود**:

```powershell
python manage.py test core.tests_smoke --verbosity=2
```

چه چیزی را می‌گیرد:
- `TemplateDoesNotExist` — تمپلیت گم‌شده
- `NoReverseMatch` — تگ `{% url %}` خراب
- `AttributeError` — فیلد مدل که وجود ندارد
- خطای ۵۰۰ از کوئری بد

### ۲.۳ سناریوهای واقعی (End-to-End)

اینها مهم‌ترین تست‌ها هستند — مسیر کامل کاربر:

#### سناریو ۱ — ثبت‌نام تا آپلود
```
1. /register/ → ثبت‌نام با نام کاربری جدید
2. باید به /onboarding/ هدایت شوی
3. فرم آنبوردینگ را پر کن
4. /creator/apply/ → درخواست Creator بده
5. /albums/create/ → یک آلبوم بساز
6. /upload/ → یک فایل صوتی آپلود کن
7. /my/tracks/ → ترک باید با وضعیت "پیش‌نویس" باشد
8. دکمه "ارسال برای بررسی" را بزن
```

**چه چیزی را چک کنی:**
- ☐ آیا هر مرحله بدون خطا انجام شد؟
- ☐ آیا پیام موفقیت (سبز) دیدی؟
- ☐ آیا فایل واقعاً آپلود شد؟

---

#### سناریو ۲ — تأیید محتوا و اعلان
```
1. با کاربر ادمین وارد /admin/ شو
2. tracks → Track → ترک آپلودشده را باز کن
3. status را به "approved" تغییر بده و ذخیره کن
4. با کاربر Creator وارد شو
5. /notifications/ → باید اعلان "ترک تأیید شد" را ببینی
6. زنگ بالای صفحه باید badge قرمز داشته باشد
```

**چه چیزی را چک کنی:**
- ☐ اعلان ساخته شد؟
- ☐ badge عدد درست نشان می‌دهد؟
- ☐ کلیک روی ✓ اعلان را خوانده‌شده می‌کند؟

---

#### سناریو ۳ — تعامل اجتماعی
```
1. با کاربر دوم (کاربر B) وارد شو
2. صفحه ترک کاربر A را باز کن
3. لایک بزن
4. کامنت بگذار
5. کاربر A را دنبال کن
6. با کاربر A وارد شو
7. /notifications/ → باید ۳ اعلان ببینی
```

**چه چیزی را چک کنی:**
- ☐ هر ۳ اعلان ساخته شد؟
- ☐ متن اعلان‌ها فارسی و درست است؟
- ☐ اگر کاربر سوم هم لایک کند، آیا گروه می‌شود؟ ("و ۱ نفر دیگر")

---

#### سناریو ۴ — سیستم امتیاز
```
1. یک ترک را پخش کن
2. حداقل ۶۰٪ آن را گوش بده (یا صبر کن)
3. /dashboard/ → امتیاز باید +۱ شده باشد
4. /admin/plays/pointledger/ → یک ردیف با delta=+1 باید باشد
```

**چه چیزی را چک کنی:**
- ☐ امتیاز ثبت شد؟
- ☐ PointLedger ردیف دارد؟
- ☐ اگر دوباره همان ترک را پخش کنی، امتیاز دوباره داده نمی‌شود؟

---

### ۲.۴ چک‌لیست موبایل

سایت را روی موبایل (یا DevTools → حالت موبایل) باز کن:

- ☐ منوی پایین (bottom nav) نمایش داده می‌شود؟
- ☐ متن‌ها بریده نمی‌شوند؟
- ☐ دکمه‌ها قابل لمس هستند (خیلی کوچک نیستند)؟
- ☐ پخش‌کننده پایین صفحه درست کار می‌کند؟
- ☐ فرم‌ها قابل پر کردن هستند؟

---

### ۲.۵ چک‌لیست خطاها

**Console مرورگر را باز کن (F12 → Console):**
- ☐ آیا خطای قرمز JavaScript هست؟
- ☐ آیا فایلی 404 می‌دهد (CSS/JS/تصویر)؟

**Network tab:**
- ☐ آیا درخواستی 500 می‌دهد؟
- ☐ آیا صفحه خیلی کند لود می‌شود؟

## بخش ۳ — تست عملکرد (Performance)

### Django Debug Toolbar (اختیاری اما مفید)

```powershell
pip install django-debug-toolbar
```

سپس در `config/settings/dev.py`:
```python
INSTALLED_APPS += ["debug_toolbar"]
MIDDLEWARE += ["debug_toolbar.middleware.DebugToolbarMiddleware"]
```

و در `config/urls.py`:
```python
if settings.DEBUG:
    import debug_toolbar
    urlpatterns += [path("__debug__/", include(debug_toolbar.urls))]
```

**چه چیزی را نگاه کنی:**
- تعداد کوئری‌های SQL هر صفحه — اگر بالای ۲۰ است، مشکل N+1 دارد
- زمان لود هر صفحه
